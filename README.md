# apartment-management-system
Modular apartment management mini ERP built with PHP/MySQLi using an API-first approach, featuring custom JWT auth, granular RBAC, and soft-delete architecture. PHP ve MySQLi ile API-first yaklaşımıyla geliştirilen; aidat, gider takibi ve dinamik rol yönetimi içeren, özel JWT ve soft-delete mimarisine sahip modüler site yönetim mini ERP sistemi.
